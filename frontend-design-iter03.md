# frontend-design-iter03.md

## Дизайнер -> Фронтендер (iter-03)

### Цели итерации на основе UX-отчета
- Сделать плановые параметры тренировки визуально очевидными в активной сессии.
- Упростить редактирование тренировок в плане.
- Свести к минимуму ручной ввод упражнений и связать план с библиотекой.
- Добавить интерфейс пост-тренировочного самочувствия.

### Интерактивные решения
1. **ActiveWorkout**
   - Под заголовком упражнения показывать блок `Цель: 4x10 @ 60kg`.
   - Чек-линия прогресса: `выполнено / запланировано` (например, `2/4`).
   - Отдельный компонент `RestTimerBar` внизу экрана (обратный отсчет + CTA "Пропустить").

2. **PostWorkoutSummary**
   - Секция "Как прошло?" с 3 контролами:
     - усталость
     - болезненность
     - качество тренировки
   - Короткий emoji-саммари с кнопкой подтверждения.

3. **Plan / WorkoutDetails**
   - В AppBar добавить меню действий: `Редактировать`, `Перенести`, `Удалить`.
   - Шит редактирования на базе AddWorkout с предзаполненными данными.
   - Для удаления — confirm dialog с названием тренировки.

4. **AddWorkout**
   - Поле упражнений заменить на searchable picker из библиотеки.
   - Добавить inline-действие `Создать новое упражнение`.
   - Отображать `exerciseId`-привязку и человекочитаемое имя.

5. **Profile / My Data**
   - Секция "Мои данные": рост, вес, цель, ограничения.
   - Кнопка "Редактировать" -> `EditProfileSheet`.

### UI-инварианты
- Один основной CTA на экран.
- Любое destructive-действие (удаление плана) — только через подтверждение.
- Текст "Цель: ..." всегда видим над формой логирования подхода.
- Тач-таргеты не менее 44px.
