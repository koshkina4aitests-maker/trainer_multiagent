# frontend-design-iter01.md

## Дизайнер -> Фронтендер (iter-01)

### Цель
Снизить когнитивную нагрузку на ключевых экранах и повысить завершение целевых действий.

### Прототипные решения
- Экран Dashboard:
  - Верхний блок с прогрессом недели (кольцевая диаграмма + CTA "Продолжить тренировку").
  - Карточки ближайших тренировок с одним основным действием.
- Экран Создания тренировки:
  - Пошаговый flow (Goal -> Duration -> Intensity -> Confirm) вместо единой длинной формы.
- Экран Питания:
  - Быстрое добавление приема пищи через "Последние шаблоны".

### UI-правила
- Primary CTA всегда один на экран.
- Пустые состояния с конкретным действием, без "тупиков".
- Текстовые подсказки валидации рядом с полем, а не только в toast.
