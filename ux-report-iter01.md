# UX Tester Report — iter-01

## Scope
- User journey: onboarding -> profile setup -> first workout plan
- Platform: mobile-first web flow
- Sample size: 8 moderated sessions

## Findings
1. Users do not clearly understand why age/weight are mandatory during onboarding.
2. First workout recommendations are perceived as "too intense" for beginners.
3. Progress charts are hard to read on small screens.
4. CTA "Start Plan" is visible, but recovery-day suggestions are not discoverable.

## Severity
- High: #1, #2
- Medium: #3
- Low: #4

## UX Recommendations
- Add contextual hints for required health fields.
- Introduce beginner-safe defaults and intensity explanation.
- Simplify chart legend and improve contrast.
- Surface recovery-day module on home screen.
