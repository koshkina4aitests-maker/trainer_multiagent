# frontend-design-iter05.md

## Дизайнер -> Фронтендер (iter-05)

### Фокус итерации
1. Профиль: убрать дефолтное имя, поддержать стиль тренировок (`split`, `fullbody`).
2. Рекомендации: спрашивать стиль (`fullbody`, `split upper`, `split lower`) и показывать детализированную структуру тренировки.
3. План: умный выбор упражнений + расширенные поля логирования и редактируемость рекомендаций.

### Ключевые UX-решения

#### 1) Профиль
- Поле имени:
  - состояние A: имя из Google-профиля (если есть);
  - состояние B: пустое поле с placeholder "Введите имя".
- Удалить любой hardcoded placeholder вроде "Алексей Смирнов".
- Новый блок "Стиль тренировок":
  - segmented control / radio chips:
    - `Fullbody`
    - `Split`
  - если выбран `Split`, показывать helper text: "Рекомендации будут учитывать день верха/низа."

#### 2) Рекомендации
- Перед генерацией рекомендации показывать шит "Стиль рекомендации":
  - `Fullbody`
  - `Split — верх`
  - `Split — низ`
- Карточка рекомендации содержит:
  - название тренировки;
  - стиль;
  - список упражнений с полями:
    - `sets`
    - `reps`
    - `weight`
    - `RIR`
- CTA:
  - `Скопировать в план`
  - `Начать тренировку`

#### 3) План
- В форме добавления/редактирования:
  - выпадающий список + умный поиск упражнений;
  - по каждому упражнению editable-поля:
    - подходы
    - повторения
    - вес
    - RIR
- Для рекомендаций, скопированных в план:
  - editable badge "из рекомендации";
  - допускается редактирование до старта тренировки.

### UI-инварианты
- Минимальный tap target: 44x44.
- Все числовые поля поддерживают локализацию RU и валидацию диапазонов.
- Ошибки валидации показывать inline рядом с полем.
